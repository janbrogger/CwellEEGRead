cadwellio - EEGLAB import plugin for Cadwell EEG
=================================================

Adds File > Import data > "From Cadwell (.ezdata / converted EDF)".
Currently imports EDF files converted by CwellEEGRead
(https://github.com/janbrogger/CwellEEGRead) through the BIOSIG or File-IO
plugin; direct .ezdata reading is planned once the format is decoded.

Install: unzip into <eeglab>/plugins/ and restart EEGLAB, or use the
plugin manager once the plugin is listed.
